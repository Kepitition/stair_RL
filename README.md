# g1-stairs-rl

Reinforcement learning for the Unitree G1 humanoid (`g1_23dof_rev_1_0`): one policy that climbs stairs and controls its step length. It trains in MuJoCo (mjlab / MuJoCo Warp) on a Windows laptop GPU.
